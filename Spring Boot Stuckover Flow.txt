1. Update
   Command : mvn clean install -U

2. Lihat versi terbaru dependency
   Command : mvn versions:display-dependency-updates

3. Auto update semua dependency ke latest
   Note : ⚠️ Ini powerful tapi hati-hati (bisa breaking)
   Command 1 : mvn versions:use-latest-releases
   Command 2 : mvn clean install

4. Update Spring Boot version (penting)
   Command : mvn versions:display-parent-updates
   Command : mvn versions:update-parent -DparentVersion=3.5.12
   Note : https://mvnrepository.com/artifact/org.springframework.boot/spring-boot-starter-parent#:~:text=Repositori%20Maven:%20org.springframework.boot%20%C2%BB%20spring-boot-starter-parent.

5. Simpan Spring Boot version
   Command : mvn versions:commit

6. Bersihkan cache dependency (kalau error aneh)
   Command : mvn dependency:purge-local-repository
